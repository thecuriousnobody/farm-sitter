# The Farm Sitter

A web platform for training, credentialing, supporting, and referring independent farm-sitting operators. It helps aspiring rural care providers launch or grow professional farm-sitting businesses, supports credential verification and optional brand licensing, and helps animal owners locate qualified sitters by geography and service type.

The product began as a validated local service operation and is now being developed into a scalable national certification, referral, and operator-support platform.
