# Affiliate / Brand License Model

## Overview

Licensed Brand Affiliate is an optional upgrade for credentialed operators. It is NOT a franchise. The platform supports territory *preference*, not territory *exclusivity*.

## Affiliate Record Fields

- Operator ID
- License start date
- License end date
- Annual fee tier
- Territory preference (geographic area)
- Status (active, expired, suspended, pending)
- Compliance flags
- Brand use approved (yes/no)
- Listing priority level

## Benefits

- Enhanced directory placement / priority referrals
- Territory preference in referral matching
- Brand-use rights (The Farm Sitter name, logo, assets)
- Brand asset downloads
- Additional business support

## Requirements

- Must hold active credential
- Annual license fee
- Compliance with brand standards
- Background check current
- Insurance current

## Territory Logic

- Affiliates may set preferred coverage areas
- Service radii define coverage
- Referral priority rules favor affiliates in their area
- Coverage gaps tracked for expansion planning
- **No exclusive franchise territories** — preference only

## Renewal

- Annual renewal cycle
- Fee payment required
- Compliance review
- Credential must remain active
